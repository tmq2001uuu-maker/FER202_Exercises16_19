# Exercise 16

Mở đúng thư mục này (có package.json) rồi chạy:

```bash
npm install
npm start
```

Không cần chạy create-react-app nữa. Dừng server bằng Ctrl+C trước khi chạy bài khác,
hoặc đồng ý dùng port khác khi Terminal hỏi. Build bằng npm run build.
Chi tiết giải thích nằm trong HUONG-DAN.md ở thư mục cha.
